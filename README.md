# リファクタリング練習教材

リファクタリングの練習用に、意図的に「ダメなコード」を30個用意しました。
各コードはリファクタリング前後で動作が変わらないことを確認するためのテストも含まれています。

## セットアップ

```bash
npm install
```

## テストの実行

```bash
# すべてのテストを実行
npm test

# ウォッチモードで実行
npm run test:watch

# カバレッジレポートを生成
npm run test:coverage
```

## ファイル構成

- `plactice/ex01.ts` 〜 `ex30.ts`: リファクタリング対象のコード
- `plactice/__tests__/ex01.test.ts` 〜 `ex30.test.ts`: 各コードのテスト

## 使い方

1. 各 `exNN.ts` ファイルを開いて、コードの問題点を確認
2. リファクタリングを実行
3. テストを実行して、動作が変わっていないことを確認
4. テストが通れば、リファクタリング成功！
